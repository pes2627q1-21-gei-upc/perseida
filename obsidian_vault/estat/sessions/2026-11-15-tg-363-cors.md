# Sessió 2026-11-15 · CORS al backend (TG-363)

## Objectiu

Que l'[[api]] respongui CORS per als orígens de DuckDNS i els ports locals de desenvolupament (US TG-363, tasques #364-#367), a la branca `feature/TG-363-cors`.

## Què s'ha fet

| Criteri / tasca | Canvi i evidència |
| --- | --- |
| C1, #364 | `CorsSettings` a `backend/app/infrastructure/api/cors.py` amb `CORS_ALLOWED_ORIGINS` (llista separada per comes) i `CORS_ALLOWED_ORIGIN_REGEX` (per defecte cap). |
| C2-C6 | `CORSMiddleware` amb els 8 orígens de la US per defecte, credencials, els 7 mètodes, `Authorization` i `Content-Type`, i `X-Correlation-ID` exposada. Mai `*`. |
| C7, #365 | `add_cors(app)` es registra abans dels altres middlewares a `create_app()`: queda el més intern (Security → Correlation → CORS → routers). El preflight es respon abans dels routers i porta el correlation id i les capçaleres de seguretat. |
| C8, #367 | Variables comentades a `infra/.env.example` i `backend/.env.example`, README d'`infra/` (en, ca, es) i [[api]]. |
| Tests, #366 | `backend/tests/unit/infrastructure/test_cors.py`: 18 casos, un per criteri, amb els orígens parametritzats. Commit `test:` (`1822394`) en vermell abans del `feat:` (`8a8321f`) ([[0028-tdd-estricte-i-politica-de-testing-avancada]]). |

### Ordres i resultats (local, sense Docker)

- `uv run pytest`: 1070 passats i 134 saltats (els d'integració, que necessiten PostgreSQL i Redis). Cobertura total del 96 %; `cors.py` al 100 %.
- `ruff check`, `ruff format --check`, `mypy` i `lint-imports`: nets.

## Decisions preses

Totes les ha aprovat Manel. Cap ADR nova: és configuració de l'API dins de [[0024-defensa-en-profunditat-contra-injeccio-sql-i-xss]].

- Els 8 orígens de la US són el valor per defecte també a producció: l'API fa servir `Bearer`, no cookies, així que admetre `localhost` no exposa cap sessió.
- `allow_headers`: només `Authorization` i `Content-Type`, les que envia el frontend.
- Les variables van comentades als `.env.example`: el render del CD només exigeix les que no ho estan, i així no cal tocar els secrets de GitHub ni `cd.yml`.

## Revisió d'arquitectura

Sense troballes crítiques ni altes. Una de mitjana, anterior a aquesta US: els 500 inesperats els resol el `ServerErrorMiddleware` de Starlette, per fora de tots els middlewares, i surten sense CORS ni capçaleres de seguretat. Des del navegador es veuen com un error de xarxa. S'ha obert la issue #599 a Taiga.
