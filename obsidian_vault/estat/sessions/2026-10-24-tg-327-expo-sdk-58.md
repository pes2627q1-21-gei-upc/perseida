# Sessió 2026-10-24 · Expo SDK 58, web i pegats de seguretat (TG-327)

## Objectiu

Que Expo Go carregui l'app al mòbil, actualitzar pnpm, Expo, Node i Python (pegats de seguretat d'octubre) i poder provar l'app a la web.

## Causa

Expo SDK 58 va sortir el 15/10/2026 i Expo Go de les botigues només admet l'SDK 58; el projecte era a l'SDK 57. No va ser cap PR de l'equip.

## Què s'ha fet

1. Expo SDK 58 (`expo@58.0.19`, React Native 0.88, React 19.3) amb versions fixades; `pnpm-workspace.yaml` neteja les exclusions de l'SDK 57 i denega els scripts de build opcionals (`allowBuilds`, obligatori amb pnpm 12). Adaptats els tipus a RN 0.88 (`ImageLoadEvent`, `Linking.openURL`).
2. pnpm 12.15.0 (`packageManager`). L'error de `pnpm add -g pnpm` és perquè pnpm ≥ 11.10 el rebutja: `pnpm self-update`.
3. Node 24.22.1 (LTS) i Python 3.14.9 (`.python-version`, Dockerfile, CI); uv de la CI a 0.13.5 perquè la 0.13.0 no coneix la 3.14.9.
4. Web: `react-dom`, `react-native-web`, `@expo/metro-runtime`; `darkMode: 'class'` a Tailwind (sense això NativeWind llança un error i la pàgina queda en blanc); `ApodVideo.web.tsx` amb `<iframe>` sandboxed.
5. Llista de hosts permesos a `ApodVideo.web.tsx` (`www.youtube.com`, `apod.nasa.gov`), alineada amb `frame-src` del CSP; un altre host mostra l'error de la pantalla.
6. `skills-sync-check.yml` i `taiga-unblock.yml` alineats a Node 24.22.1 i Python 3.14.9; skill `estetica-frutiger-cosmo` revisada per a l'SDK 58.
7. Patch de pnpm (`frontend/patches/react-native-css-interop@0.2.7.patch`) que treu el registre d'`ImageBackground` de `react-native-css-interop`: RN 0.88 el marca com a obsolet i el warning sortia a Expo Go. L'app no l'usa amb `className`.
8. Jest: `testTimeout` de 30 s (en fred, el primer render de cada fitxer superava els 5 s).

## Decisions

- **TypeScript es queda a 6.0.3**: TypeScript 7.0.2 no exposa l'API clàssica del compilador i `typescript-eslint` (fins i tot el canary) exigeix `<6.1`. Es revisarà quan hi hagi suport. No hi ha ADR nou: és una actualització de versions.

## Pendents

- Provar a un mòbil real amb Expo Go (SDK 58) i a Android/iOS.
- **Treure les excepcions de pnpm** (`minimumReleaseAgeExclude` a `frontend/pnpm-workspace.yaml`, ~17 paquets de l'SDK 58) quan passi la finestra de `minimumReleaseAge`: esborrar-les i comprovar que `pnpm install --frozen-lockfile` segueix net.
- **Treure el patch de `react-native-css-interop`** (`patchedDependencies` a `frontend/pnpm-workspace.yaml` i `frontend/patches/`) quan NativeWind publiqui una versió que ja no registri `ImageBackground`; si només es puja la versió, el patch deixa d'aplicar-se i `pnpm install` falla.
- Revisar TypeScript 7 quan `typescript-eslint` el suporti.
